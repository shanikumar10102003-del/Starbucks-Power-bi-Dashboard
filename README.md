# ☕ Starbucks Power BI Dashboard

An interactive Power BI dashboard built using Starbucks beverage nutrition data. This project demonstrates data visualization, dashboard design, and business intelligence skills using Power BI, Power Query, and DAX.

---

## 📌 Project Overview

The Starbucks Power BI Dashboard provides insights into beverage nutrition and category performance through interactive visualizations. It helps users explore calories, sugar, caffeine, protein, and beverage preparation options in a simple and visually appealing dashboard.

This project is designed as a portfolio project to showcase Power BI skills for Data Analyst roles.

## 🎯 Project Objectives

- Analyze Starbucks beverage nutritional information.
- Compare different beverage categories.
- Identify high-caffeine beverages.
- Understand calorie and sugar distribution.
- Display Starbucks' global presence.
- Create an interactive dashboard using Power BI.

---

## 📁 Dataset

The dataset contains nutritional information for Starbucks beverages, including:

- Beverage Name
- Beverage Category
- Beverage Preparation
- Calories
- Sugar (g)
- Protein (g)
- Caffeine (mg)

---

## 📈 Dashboard Features

### KPI Cards

- Total Beverages
- Average Sugar
- Average Calories
- Average Caffeine

### Interactive Filters

- Protein Range Slider
- Beverage Preparation Slicer

### Visualizations

- Average Calories by Beverage Category
- Starbucks Global Presence Map
- Beverage Category Distribution (Donut Chart)
- Average Caffeine by Category
- Top 5 Highest Caffeine Beverages

---

## 💡 Key Insights

- Coffee has the highest average caffeine content.
- Frappuccino beverages contain higher average calories.
- Beverage preparation impacts nutritional values.
- The dashboard provides quick comparisons across beverage categories.
- Interactive filters allow users to explore data dynamically.
